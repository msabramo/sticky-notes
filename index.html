✨ Start a New Board

Tap + to add a note. Drag a note's colored header to move it, tap its body to type, and drag its bottom-right corner to resize it. Use the ● button to change its color, and the Aa button for bold/italic/underline, headings, fonts, and size — select some text first to format just that part. Use the 🏷 button on a note to set custom fields (status, assignee, tags, or whatever you define in Manage Fields — including a Person field that auto-fills from everyone who's used this board). Tap the circle next to ☰ to set your name, initials, and color so others can tell who's who. Tap 📷 to snap a photo of a handwritten or printed to-do list and turn each item into its own note. Everyone with the invite link edits this same board live. Pinch, scroll, or use the +/− buttons to zoom; drag empty space to pan.
